# Support CRM Dashboard

A simple Support CRM Dashboard built using FastAPI, SQLite, React, and Axios.

## Features

- Create support tickets
- Search tickets by customer name
- Filter tickets by status
- Close tickets
- REST API with FastAPI
- React frontend dashboard
- SQLite database

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- SQLite

### Frontend
- React
- Vite
- Axios
